🎯 What Is MultiClip?

MultiClip is a clipboard workstation that lives on your MX Linux desktop. It gives you:

  • 30 workbench slots for storing clipboard snippets
  • Global hotkeys — copy/paste to any slot without touching the mouse
  • Live clipboard history — every Ctrl+C you do gets captured automatically
  • Orderly mode — auto-capture into sequential slots with FIFO/LIFO paste
  • 8 persistent snippets that survive reboots
  • Visual feedback — gold/green flashes on every transfer

🔑 Sacred Invariants

NEVER CHANGE THESE without extensive real-world testing:

  1. Hotkey Contract: LCtrl + LAlt + digit = COPY to slot. RCtrl + RAlt + digit = PASTE from slot.
  2. Root Execution: App runs as root on MX Linux. X11 auth via /tmp/.Xauthority_multiclip.
  3. xdotool First: Paste injection prefers xdotool over pyautogui (more reliable under root).
  4. 30 Slots, 8 Snippets: Fixed counts. No SQLite, no new file formats.
  5. clipboard_dict.json and snippets.json are the ONLY data files.

🚀 Boot Sequence

1. SysVinit runs /etc/init.d/multiclip (as root)
2. Copies ~/.Xauthority → /tmp/.Xauthority_multiclip
3. Sets DISPLAY=:0, XAUTHORITY=/tmp/.Xauthority_multiclip
4. Runs .venv/bin/python3 multiclip.py
5. fcntl.flock on /tmp/multiclip.lock (prevents duplicates)
6. Loads clipboard_dict.json + snippets.json
7. Starts pynput hotkey listener (background thread)
8. Starts HybridClipboardMonitor (pynput + poll threads)
9. Builds MainWindow tkinter UI
10. Wires callbacks between UI and core engine
11. Enters tkinter mainloop
