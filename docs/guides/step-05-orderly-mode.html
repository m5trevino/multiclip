🎯 Step 5 — Orderly Mode

Auto-capture clipboard into sequential slots. FIFO/LIFO paste with independent copy/paste cursors. Wraps 30→1.

🎛️ How Orderly Mode Works

  1. User clicks "Orderly" radio button in toolbar
  2. Orderly monitor starts (300ms timer loop)
  3. Every Ctrl+C in any app → auto-captured into next slot
  4. Copy cursor advances (wraps 30→1)
  5. User clicks "Paste Next" button → pastes from paste cursor
  6. Paste cursor advances (FIFO: forward, LIFO: backward)

📊 State Variables

self.orderly_active = False           # Is Orderly mode running?
self.orderly_submode = "fifo"         # "fifo" | "lifo"
self.orderly_copy_cursor = 1          # Next slot to FILL (1-30)
self.orderly_paste_cursor = 1         # Next slot to PASTE FROM (1-30)
self.orderly_wrap_count = 0           # How many times we've wrapped
self.orderly_last_clip_hash = ""      # MD5 of last captured content
self.orderly_last_capture_time = 0    # Timestamp for debounce

🔄 Independent Cursors Explained

Copy Cursor

Purpose: Where the next Ctrl+C copy will go

Advances on: Every new clipboard capture

Wrap: 30 → 1 (circular buffer)

Highlight: Orange (#ff9966)

Copied slots 1-60
Copy cursor = 61 → wraps to 1
User copies 70-80
Copy cursor = 11

Paste Cursor

Purpose: What will be pasted on next "Paste Next"

Advances on: Every "Paste Next" click

Wrap: 30 → 1 (FIFO) or 1 → 30 (LIFO)

Highlight: Green (#66ff66)

User pasted slots 60-67
Paste cursor = 68
User copies 70-80
Paste cursor STAYS at 68
Key Design Decision: Copy and paste cursors are INDEPENDENT. You can copy 100 items while only pasting 10 — the paste cursor remembers where it left off. The "next paste slot" is always highlighted in green on the workbench.

def start_orderly_monitor(self):
    self.orderly_active = True
    self._orderly_tick()
    print("[ORDERLY] Monitor started")

def _orderly_tick(self):
    if not self.orderly_active:
        return
    self._orderly_clip_check()
    self.orderly_timer = threading.Timer(0.3, self._orderly_tick)
    self.orderly_timer.daemon = True
    self.orderly_timer.start()

def _orderly_clip_check(self):
    if not self.orderly_active:
        return
    content = pyperclip.paste()
    if not content or not content.strip():
        return

    # Debounce: min 100ms between captures
    now = time.time()
    if now - self.orderly_last_capture_time < 0.1:
        return

    # Hash deduplication
    h = hashlib.md5(content.encode()).hexdigest()
    if h == self.orderly_last_clip_hash:
        return

    # Don't capture if same as target slot (safety)
    target_slot = str(self.orderly_copy_cursor)
    if self.slots.get(target_slot) == content:
        return

    # Don't capture if GUI is focused (user typing inside MultiClip)
    if self._is_gui_focused():
        return

    # CAPTURE
    self.orderly_last_clip_hash = h
    self.orderly_last_capture_time = now
    self.slots[target_slot] = content
    self.save_slots()

    # Update UI
    self.ui.slot_displays[copy_cursor - 1].update_content(content, preview)
    self.ui.flash_slot(copy_cursor - 1)  # gold pulse

    # Advance copy cursor
    self.orderly_copy_cursor += 1
    if self.orderly_copy_cursor > 30:
        self.orderly_copy_cursor = 1
        self.orderly_wrap_count += 1

    # Highlight next copy target (orange)
    self.ui.clear_slot_highlight(all)
    self.ui.highlight_slot(copy_cursor - 1, color="#ff9966")

def orderly_paste_next(self):
    slot = self.orderly_paste_cursor
    content = self.slots.get(str(slot), "")
    if not content:
        self.show_toast("ORDERLY PASTE", f"Slot {slot:02d} is empty")
        return

    # Load clipboard and inject
    pyperclip.copy(content)
    time.sleep(0.12)
    self._release_all_modifiers()
    time.sleep(0.06)

    # xdotool injection (terminal-aware)
    if self._is_terminal():
        subprocess.run(["xdotool", "key", "--clearmodifiers", "ctrl+shift+v"])
    else:
        subprocess.run(["xdotool", "key", "--clearmodifiers", "ctrl+v"])

    # Advance paste cursor
    if self.orderly_submode == "lifo":
        self.orderly_paste_cursor -= 1
        if self.orderly_paste_cursor < 1:
            self.orderly_paste_cursor = 30
    else:  # fifo
        self.orderly_paste_cursor += 1
        if self.orderly_paste_cursor > 30:
            self.orderly_paste_cursor = 1

    # Highlight next paste target (green)
    self.ui.clear_slot_highlight(all)
    self.ui.highlight_slot(paste_cursor - 1, color="#66ff66")

    self.show_toast(f"ORDERLY PASTE ← Slot {slot:02d}", preview)

🎛️ FIFO vs LIFO

ModePaste OrderCursor DirectionUse Case
FIFOSlot 1, 2, 3, 4...Forward (+1, wrap 30→1)Replay clips chronologically
LIFOSlot 30, 29, 28...Backward (-1, wrap 1→30)Access most recent first

Example: Slots 1-5 filled with [A, B, C, D, E]

FIFO paste sequence:  A → B → C → D → E → A → B...
LIFO paste sequence:  E → D → C → B → A → E → D...

🧪 Testing Orderly Mode

# 1. ACTIVATE
Click "Orderly" radio button
→ "[ORDERLY] Monitor started" in console
→ FIFO/LIFO buttons appear

# 2. AUTO-CAPTURE TEST
Open a text editor
Select text → Ctrl+C
→ Slot 1 should fill
→ Slot 1 flashes gold
→ Copy cursor moves to slot 2 (orange highlight)

Copy different text → Ctrl+C
→ Slot 2 should fill
→ Continue to slot 30...

Copy one more → Ctrl+C
→ Slot 1 should OVERWRITE (wrap)
→ Wrap count increments

# 3. FIFO PASTE TEST
Click "Paste Next" button
→ Content from slot 1 pastes
→ Paste cursor moves to slot 2 (green highlight)

Click "Paste Next" again
→ Content from slot 2 pastes
→ Paste cursor moves to slot 3

# 4. LIFO PASTE TEST
Click "LIFO" button
Click "Paste Next"
→ Content from most recently filled slot pastes
→ Paste cursor moves backward

# 5. DEACTIVATE
Click "Multiclip" radio button
→ "[ORDERLY] Monitor stopped"
→ All highlights clear
