How content moves from Clipman History to Workbench slots. Block Bundle vs 1 slot per line.

📋 Transfer Modes

📦 Block Bundle

Button: "Block Bundle" (was "TRANSFER AS BATCH")

Behavior: All selected items are concatenated with newlines and placed into one slot. If multiple items selected, fills empty slots first.

selected = [entry1, entry2, entry3]
→ Fills slot 1 with entry1
→ Fills slot 2 with entry2  
→ Fills slot 3 with entry3
(start_slot=None = empty-first mode)

📄 1 Slot Per Line

Button: "1 slot per line" (was "TRANSFER AS ONE SLOT")

Behavior: Each selected item gets its own slot. Two sub-modes:

  • Auto-Sequential: Fills from next empty slot (1→30)
  • Manual: User clicks a workbench slot first → fills from there
selected = [entry1, entry2]
Manual mode, clicked slot 10:
→ Slot 10 = entry1
→ Slot 11 = entry2

🔧 Mode Toggle: Auto-Sequential vs Manual

The mode toggle widget lives under the "1 slot per line" button in the Clipman History panel:

slot_mode_var = tk.StringVar(value="Auto-Sequential")
# Options: "Auto-Sequential" | "Manual Slot"

# Auto-Sequential: start_slot = None
# Manual: user clicks a workbench slot to set start_slot

Manual Slot Selection Flow

1. User switches to "Manual Slot" mode
2. User left-clicks a Workbench slot (e.g., slot 10)
3. Slot gets temporary highlight (gold background)
4. User selects items in Clipman History
5. User clicks "1 slot per line"
6. Items fill starting from slot 10, wrapping 30→1

📄 Core Transfer Code

_transfer_clipman_to_og_slots() — multiclip.py lines 214-284

def _transfer_clipman_to_og_slots(self, selected_entries, start_slot=None):
    """
    start_slot=None  → Block Bundle mode (fill empty slots first)
    start_slot=N     → 1 slot per line (fill sequentially from N, wrap 30→1)
    """
    contents = []
    for item in selected_entries:
        if isinstance(item, str):
            contents.append(item)
        elif hasattr(item, 'decoded_content'):
            contents.append(item.decoded_content)
        else:
            contents.append(str(item))

    filled = []
    if start_slot is not None:
        # 1 SLOT PER LINE: sequential fill with wrap
        slot = start_slot
        for content in contents:
            self.slots[str(slot)] = content
            filled.append(slot)
            slot += 1
            if slot > 30:
                slot = 1
    else:
        # BLOCK BUNDLE: fill empty slots first
        empty_slots = [i for i in range(1, 31) if not self.slots.get(str(i))]
        for content in contents:
            if empty_slots:
                slot = empty_slots.pop(0)
                self.slots[str(slot)] = content
                filled.append(slot)
            else:
                # SLOTS FULL dialog
                slot = simpledialog.askinteger(
                    "SLOTS FULL",
                    "Type a slot number (1-30) or Cancel to overwrite slot 1",
                    minvalue=1, maxvalue=30, initialvalue=1
                )
                ...

    self.save_slots()
    self._refresh_slot_displays(filled)
    self.show_toast(title, preview)
    return filled
