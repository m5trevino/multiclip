🔒 Single-Instance Guard

Uses fcntl.flock on a lockfile in /tmp (visible to both root and flintx):

def _ensure_single_instance(self):
    lock_path = "/tmp/multiclip.lock"
    self._lock_file = open(lock_path, "w")
    try:
        fcntl.flock(self._lock_file, fcntl.LOCK_EX | fcntl.LOCK_NB)
    except BlockingIOError:
        print("[MULTICLIP] Another instance is already running. Exiting.")
        sys.exit(1)

Mechanism: Exclusive non-blocking lock. If another process holds the lock, the new instance exits immediately.

Cleanup: Lock is released when the process terminates (kernel handles this automatically).

🖥️ SysVinit Service

Service Location

/etc/init.d/multiclip          # Service script
/etc/rc2.d/S03multiclip          # Boot symlink (runlevel 2)
/etc/rc3.d/S03multiclip          # Boot symlink (runlevel 3)
/etc/rc4.d/S03multiclip          # Boot symlink (runlevel 4)
/etc/rc5.d/S03multiclip          # Boot symlink (runlevel 5)

What the Service Does

1. Detects the desktop user (who owns DISPLAY :0)
2. Copies user's ~/.Xauthority → /tmp/.Xauthority_multiclip
3. Sets environment:
   - DISPLAY=:0
   - XAUTHORITY=/tmp/.Xauthority_multiclip
   - HOME=/home/flintx
4. Runs: cd /home/flintx/multiclip && .venv/bin/python3 multiclip.py

Launcher Script

/home/flintx/multiclip/multiclip-launcher.sh
#!/bin/bash
cd /home/flintx/multiclip
export DISPLAY=:0
export XAUTHORITY=/tmp/.Xauthority_multiclip
exec /home/flintx/multiclip/.venv/bin/python3 multiclip.py

📄 Emergency Save on Exit

import signal, atexit

def _emergency_save():
    try:
        self.save_slots()                    # Persist workbench
    except: pass
    try:
        self.clipboard_monitor.stop()        # Stop monitor threads
    except: pass
    try:
        self._stop_orderly_timer()           # Stop Orderly timer
    except: pass

atexit.register(_emergency_save)
for sig in (signal.SIGINT, signal.SIGTERM):
    signal.signal(sig, lambda s, f: (_emergency_save(), sys.exit(0)))
