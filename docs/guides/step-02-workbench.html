Left column: Slots 1 (top) → 15 (bottom)
Right column: Slots 16 (top) → 30 (bottom)

🔧 SlotDisplay Widget

Each slot is a SlotDisplay (ttk.Frame) containing:

WidgetPurposeInteraction
Order EntryNumeric input (width=3)FocusOut triggers reorder callback
ID LabelS01, S02, ... S30Visual reference
Preview LabelContent preview (50 chars max)Left-click = select, Right-click = edit
Status LabelCharacter countBlue when filled, gray when empty

💾 Persistence

Slots are saved to clipboard_dict.json in the project root:

{
  "slots": {
    "1": "content of slot 1",
    "2": "content of slot 2",
    ...
    "30": ""
  }
}

Load path: MultiClipV2.load_slots() (lines 99-120)
Save path: MultiClipV2.save_slots() (lines 122-124)
Emergency save: Registered in atexit and SIGINT/SIGTERM handlers

SlotDisplay class — lines 187-256

class SlotDisplay(ttk.Frame):
    def __init__(self, parent, slot_id, on_select, on_order_change, on_edit):
        super().__init__(parent)
        self.slot_id = slot_id
        self._create_widgets()  # Order Entry + ID + Preview + Status

    def update_content(self, content: str, preview: str):
        self.preview_label.config(text=clean_preview[:50])
        if content:
            self.status_label.config(text=str(len(content)), fg='blue')
            self.preview_label.config(bg='#e8f4ff')  # light blue when filled
        else:
            self.status_label.config(text="0", fg='gray')
            self.preview_label.config(bg='white')    # white when empty

    def set_order(self, order_num: int):
        self.order_var.set(str(order_num))

# Left column: slots 1-15 (0-based indices 0-14)
for i in range(15):
    slot = SlotDisplay(self.slots_inner, i, self._on_slot_select,
                       self._on_order_change, self._on_slot_edit)
    slot.grid(row=i, column=0, sticky='ew', padx=2, pady=1)
    self.slot_displays[i] = slot

# Right column: slots 16-30 (0-based indices 15-29)
for i in range(15):
    slot_idx = 15 + i
    slot = SlotDisplay(self.slots_inner, slot_idx, ...)
    slot.grid(row=i, column=1, sticky='ew', padx=2, pady=1)
    self.slot_displays[slot_idx] = slot
