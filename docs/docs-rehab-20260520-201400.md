# 00-EXECUTIVE_OVERVIEW.md

MultiClip V2 - Industrial Workstation
An advanced sequential clipboard manager for MX Linux, designed for high-density slot management (30 slots), terminal-aware hotkeys, and persistent snippet storage. 

## Key Features
- **30-Slot High-Density Grid**: Workspace for 30 distinct clipboard entries with custom sequencing.
- **Terminal-Aware Paste Engine**: Uses xdotool to automatically toggle between standard Ctrl+V and terminal Ctrl+Shift+V.
- **Persistent Snippet Vault**: Dedicated space for non-volatile text, accessed via Win+Alt+1-0.
- **Industrial Parsing**: Robust state-machine parser for clipman `textsrc` files.
- **Conflict-Free Hotkeys**: Decoupled from system Super-key bindings for reliable operation.
