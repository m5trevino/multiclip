Key Decisions

#1 — Abandon textsrc entirely
xfce4-clipman's plugin_save() deletes entire cache dir (g_unlink loop in plugin.c:226-236). File is fundamentally unreliable.
#2 — Self-owned clipboard monitor
Build our own capture inside multiclip. JSON persistence to ~/.cache/multiclip/clipboard_history.json. Full control.
#3 — SysVinit only
Removed systemd service and XFCE autostart. Only /etc/init.d/multiclip remains. Fixed symlinks to S03.
#4 — Keep root execution
2 years of proven operational history. pynput + global hotkeys require root on this MX Linux setup.
#5 — Single-instance guard
fcntl.flock on /tmp/multiclip.lock prevents boot duplication.
